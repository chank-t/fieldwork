# Optional sprite generation tools

The project ships with already generated art. Python generators in this folder are **not needed** to run or import the game.

Regenerating assets may require Pillow (`python3 -m pip install Pillow`) and can overwrite artwork under `assets/`. Back up files or use version control before running any generator. Some helper scripts were originally used during older art-production milestones and should not be mistaken for Godot build steps.

For current gameplay and release testing use `README.md` and `docs/BUILD_AND_TEST.md` instead.
