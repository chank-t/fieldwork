# Fieldwork 6.0 documentation index

**Source basis:** the actual native 6.0 Godot project. The guides distinguish implemented code paths from features that still need live engine validation.

1. [PDF manual](FIELDWORK_6_0_MANUAL.pdf): a portable combined player and developer handbook.
2. [Player guide](PLAYER_GUIDE.md): create a farmer; move, plant and explore; identify the main screens.
2. [Architecture](ARCHITECTURE.md): boot flow, simulation and presentation scripts, transaction model.
3. [Action API](ACTION_API.md): mutation types and source-derived argument keys.
4. [Content and data](CONTENT_AND_DATA.md): data-driven catalogs, content inventories, important asset rules.
5. [Saves and migration](SAVES_AND_MIGRATION.md): checksum, backups, JSON schema, old-version sources.
6. [Build and tests](BUILD_AND_TEST.md): Godot installation, headless tests, screen matrix and Android export prerequisites.
7. [Limitations and roadmap](LIMITATIONS_AND_ROADMAP.md): real technical debt and unfinished verification.
8. [Cleanup report](CLEANUP_REPORT.md): removed vs retained files; no gameplay mutations.
9. [6.0 Farm Compass design](COMPLETE_FARMING_6_0.md): detailed 6.0 completion paths.
10. [Release history](VERSION_HISTORY.md): what features entered in each release.

`history/` stores previous design notes and legacy reference data. These files are optional and are not read by the running game.
