# Cleanup report - Fieldwork 6.0

## Purpose

Keep the Godot source tree clean and editable while normalizing version-tagged code/test filenames, **without changing gameplay rules or save behavior**.

## Cleanup actions

- Removed the former `evidence/` directory of historical QA logs, image previews and release manifests. These files are not runtime dependencies and remain accessible in the original 6.0 ZIP.
- Removed version-specific Python audit scripts from `tests/` other than the current `qa.py`; historical checks expected old file paths and version labels. All native Godot `*.gd` regression smoke tests were kept.
- Removed old generated QA outputs and preview helper scripts from the runnable test directory.
- Renamed version-tagged gameplay modules, QA tooling and smoke tests to descriptive version-neutral filenames; updated imports, runners, docs and Godot UID sidecars.
- Removed tracked Godot editor, imported-resource and shader caches. These generated directories are now ignored and will be regenerated by Godot.
- Moved older feature guides and two obsolete development data references into `docs/history/`; **the current runtime data files remain in `data/`**.
- Added a clear entrypoint README, consolidated current documentation, and `.gitignore` for temporary/editor-generated files.
- Kept gameplay logic, save schema, scenes, loaded assets and referenced artwork unchanged. GDScript preload paths were updated only to match the renamed modules; current file hashes are recorded in `docs/CLEANUP_MANIFEST.json`.
- Preserved the current 6.0 offline audit with an updated inherited-art baseline reflecting the deliberate relocation of non-runtime historical reference data.

## Scope and limitations

This is **a packaging/source-tree cleanup, not a gameplay rewrite**. A few oversized code modules remain oversized by design for now; refactor them only after Godot parser and gameplay tests can run. No new game mechanics, executable builds, Android export settings or save-schema changes were introduced.

To repeat the offline verification run `python3 tests/qa.py`. To test the actual engine run `RUN_NATIVE_TESTS.sh` or `.bat` with Godot installed.
