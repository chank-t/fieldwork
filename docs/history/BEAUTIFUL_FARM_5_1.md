# Fieldwork 5.1 — A Beautiful Farm

## Design and scope

This release follows the priorities agreed after 5.0: the farm should become the center of the game; controls should appear close to the objects they change; and soil, crops and paths should look more differentiated without losing their relationship to simulation state. It is a **presentation upgrade**, not a new agricultural content release.

## Mapping and visual facts

- **Soil status**: dry = less than 19% root-zone capacity; wet = more than 77%; other conditions use the named terrain material. The existing world renderer also retains 5.0's visible water and pest indicators. The visual threshold is not a simulation threshold.
- **Moisture layer**: `water / capacity`.
- **Growth layer**: `crop.development`; an empty plot has zero growth.
- **Soil layer**: normalized version of the game's existing soil vitality parameters (organic matter, compaction and erosion). This view is indicative and is not an independent laboratory measurement.
- **Pest layer**: largest current pest density normalized to 40 game units. The overlay does not reveal new information unavailable in the state to a full-inspection panel; it is a readability aid.
- **Display only**: all visual modes are deterministic and read-only, and the old 5.0 game/catalog datasets remain byte-for-byte identical. Map panning and zooming do not advance the clock or RNG.

## UI acceptance criteria

- On a normal desktop window the sidebar starts collapsed, preserving more width for the live farm. It can be toggled without reconstructing or resetting the game.
- The selected field summary never offers watering on unowned land or harvesting when the crop is immature; transaction checks are still authoritative in `NativeFarm.gd`.
- Opening all screens makes every inherited tab reachable and selecting one returns to the living farm layout with the correct management panel open.
- Language changes update map-layer labels and the field summary. Settings are persistent and independent of farm save data.
- Full-screen map displays the same overlay setting and farm state as the small map.
- At small window sizes the game retains horizontal scrolling/navigation and the existing compact, scrollable screen layout.
- Save migration preserves the former campaign and keeps the 5.0 path untouched. Test both a valid 5.0 save and a damaged current 5.1 save with valid backup.

## Known limitations and next steps

- No Godot binary was available in the authoring environment; test actual parser/compiler, mouse hit boxes, visual clipping, animations and save migration in Godot before considering this runtime-verified.
- Crop roster is unchanged; new plot types and crop species are candidates for 5.2, and a full pre-game character creator is intended for a possible later release.
- The 24 plot layout remains the existing grid. A free-form field placement system would require broader simulation/gameplay changes and is not present in 5.1.
- The concept preview is not a screenshot generated by Godot and is marked as such.
