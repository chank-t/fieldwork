# Godot 4.3 verification checklist

## Run tests in a real Godot 4.4+ installation

From the extracted project root (install `Pillow` for the optional Python preview renderer):

```sh
python3 tests/static_audit.py
python3 tests/visual_layout_preview.py
godot --headless --path . --editor --quit
godot --headless --path . --script res://tests/native_smoke.gd
godot --headless --path . --script res://tests/layout_smoke.gd
```

The first two are offline Python checks; the last three **require the Godot executable**. The authoring environment ran only the Python checks. The project has not been certified playable in the engine.

## Visual manual QA (not yet executed in Godot)

1. Launch `Boot.tscn` in Godot, verify the cover and both startup buttons are visible. Click Start. The creator must scroll, and character fields must remain legible at 390x844 and 1440x900.
2. Open every creation dropdown (hair, skin, clothes, background, mode, difficulty), check dark text over a light background, visible arrow, correct preview, and no clipping.
3. Create a new farm. Check that the 24 plots have badges, one is owned, and selecting plot 24 updates the badge outside the world. Test by clicking the plot and using the dropdown.
4. Set time to night/rain and confirm the selected plot indicator remains visible. Zoom from 1.0x to 2.0x and check labels and click positions.
5. Gather timber and flowers on the Resources tab. Verify actual energy, game hours, cost and inventory changes. Repeat the same region during the same game day: it must fail atomically.
6. Craft and complete a bench. Confirm it renders in the garden path instead of on top of a building; click to inspect it. Try a second item in the occupied position: it must be rejected without a charge.
7. Earn 220 XP, check level 2, one new talent point, mastery progress, and a level-up log; repeated inspection must not give repeated same-day XP.
8. Check the animal yard, new decorations, the mobile navigation bar, the character portrait, and Spanish labels.
9. Load a backed-up 4.1 or 4.2 native save. Check the owned plots, money, crops, inventory, RNG, and new resource roots; save again as 4.3.
10. Test an unowned field purchase, low cash, insufficient storage, a resolved event, and save/load while a building or decoration is under construction.

## Known limits

- The native 4.3 simulation remains an **adapted** implementation, not numerically identical to the complete web game.
- The world remains 2D and has fixed building/decoration locations.
- No new APK, hosted synchronization, or multiplayer service is provided.
- Godot runtime parsing, in-engine visual screenshots, desktop GPU testing, and Android testing are **unverified in this release**.
