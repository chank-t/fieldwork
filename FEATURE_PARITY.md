# Feature preservation - Fieldwork 6.0 Clean

This edition preserves the full original Fieldwork 6.0 runtime. There was **no simulation refactor or content rebalance**.

- World: classic 2D and isometric-style 2.5D, PC/mobile layouts, regional map and interiors.
- Farming: 24 plots, 27 crops, different plot layouts, soil/ecology/pests, animal care and machinery.
- Economy: construction, processing, trade, farm specializations and quests.
- Personalization: farmer appearance, outfits, garden decoration placement and relocation.
- Community: authored choices, ten NPCs, neighbour story chapters, festivals, certifications, eight region projects.
- Quality-of-life: Farm Compass, colour-independent overlays, UI scaling, three performance modes, local saves and backup recovery.

**Source protection:** the SHA-256 manifest at `docs/CLEANUP_MANIFEST.json` records unchanged game/asset files. The project was **not runtime-verified** with the Godot engine in this environment.
